# Рейтинг ЭТП 44-ФЗ

Интерактивный рейтинг восьми электронных площадок по 44-ФЗ: Сбербанк-АСТ, РТС-тендер, Росэлторг, ЭТП ГПБ, Фабрикант (НЭП), РАД, ТЭК-Торг, ЗаказРФ.

**Открыть:** https://albert-tech.github.io/etp-rating/

Сводный балл собирается из трёх блоков с настраиваемыми весами:

- **Функционал** — 50 критериев и стоимость банковской гарантии;
- **Масштаб** — доля площадки по числу процедур и по НМЦК (01.01.2025–30.09.2026);
- **Конкуренция и качество** — среднее число заявок, доля конкурентных и безрезультатных закупок, жалобы, экономия (средние за 2025–2026).

Методика расчёта описана внизу страницы. Всё в одном файле `index.html`, без сборки.
